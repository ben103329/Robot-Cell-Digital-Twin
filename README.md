# \# Robot Cell Digital Twin

# 

# Industrial Automation | PLC | Robotics | Digital Twin

# 

# \## 1. Project Overview｜專案介紹

# 

# 本專案旨在研究與重建既有工業自動化控制系統，透過 PLC、工業機械手臂及虛擬產線模擬，逐步建立具備虛實整合能力的 Digital Twin 系統。

# 

# \## 2. Hardware｜硬體設備

#

# \- FANUC LR Mate 200iD Robot

# \- FANUC Robot Controller

# \- MOXA EDS-208 Ethernet Switch

# \- Teach Pendant
